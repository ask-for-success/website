# Project Instructions

## Language

English is the primary and mandatory language for this project.

Write every project artifact entirely in English. This includes code, comments,
identifiers, class names, function names, file and folder names, database schemas,
SQL scripts, API routes and fields, OpenAPI descriptions, tests, documentation,
planning files, README files, reports, and Postman collections.

Do not use French or any other language in project artifacts unless the user
explicitly requests that language for one specific deliverable.

Use English for conversation by default. Do not infer a language preference from
existing files. When modifying an existing French artifact, translate the relevant
artifact into English instead of adding more French content.
