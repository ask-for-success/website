# Instructions du projet

## Langue

Tous les livrables du projet doivent être entièrement rédigés en français. Cette règle concerne le code, les commentaires, les identifiants, les noms de fichiers et de dossiers, les schémas de base de données, les routes et champs API, les descriptions OpenAPI, les tests, la documentation, les fichiers de planification, les fichiers README, les rapports et les collections Postman.

Ne pas utiliser l'anglais ou une autre langue dans un livrable du projet, sauf demande explicite de l'utilisateur pour un livrable précis.

La conversation avec l'utilisateur peut se dérouler en anglais, mais les fichiers du projet restent en français par défaut.
