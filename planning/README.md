# Planning

This folder contains only active project-management documents:

- [PROJECT_PROGRESS.md](./PROJECT_PROGRESS.md): current status, next step, and delivery phases;
- [WORKFLOW.md](./instructions/WORKFLOW.md): process required for every feature;

Functional requirements and approved decisions remain in the [main documentation](../docs/README.md) so they are not duplicated in planning files.
